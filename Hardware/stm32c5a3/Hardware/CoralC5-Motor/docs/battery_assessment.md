# 2800mAh三串电池评估

评估日期2026-10-27。范围为CoralC5-Core、本双电机扩展板和两台MG513XP28_12V。用户目标约一小时，不计摄像头、荔枝派或其他大功率外设。

**2800mAh有达到一小时的能量余量，适合这版小车起步。续航仍取决于落地平均功耗，不能从额定电流保证时长。**

用户图片的2800mAh款为3S1P，电压9～12.6V、约170g、约68×55×19mm，标称最大持续8A、瞬时16A、用电器小于70W。以上为商家图片参数，本项目没有测量电芯容量、内阻、保护板或瞬时电流允许时间。

3S的12.6V是充满电压，标称电压通常为10.8～11.1V。按11.1V计算，11.1×2.8=31.08Wh；考虑截止、损耗、温度、容量差异和预留，以75%～85%可用比例估计约23～26Wh。该比例是设计假设，不是实测值。

| 电池端平均整机功耗 | 估计续航 |
| --- | --- |
| 10W | 约2.3～2.6小时 |
| 15W | 约1.5～1.7小时 |
| 20W | 约1.15～1.3小时 |
| 25W | 约0.9～1.05小时 |
| 30W | 约0.75～0.9小时 |

一小时目标建议实测平均功耗控制在20～22W以内，保留余量。5600mAh同时增加约150g，目前没有必要只为一小时直接换更大的电池。

参考项目 `D:/dev/EdgeMind-Robot/doc/电机/拟用电机资料核对.md` 已记录实物型号及WHEELTEC系列手册的MG513X参数，12V、额定0.36A、堵转3.2A、1:28。手册使用系列名，实际批次和负载仍需测量，不能混用MG513XL的1A/6A数据。

两台若处在系列额定电流附近，电机端约2×12×0.36=8.64W。加核心板、编码器、驱动和电源损耗，可以先按10～12W场景估计，对应约2小时上下。此场景不代表实际赛道，急弯、反复启停、轮胎摩擦和机械负载可能提高平均电流。

本板每路初始限流约2.0A。按满占空比、器件误差及0.75A五伏预算，低电量时需按接近5A的短时入口需求审视插座、线束和驱动，不能把电池8A标称视为整板8A能力。长时间堵转不是持续工况；未经限流的两台系列堵转电流合计6.4A，与本板正常运行限流不同。

验收时装上实际轮胎和车重，在电池侧记录代表性赛道下的电压、电流及累计Wh，包含弯道和启停，再做完整一小时运行。同步检查压降、DC线、插座、MOSFET、驱动和降压温升，核实编码器电流，所有3.3V外接负载仍限100mA。

本板DC输入用于放电供电。充电需匹配3S电池的充电与保护方案，本板不测单节电压，不能替代BMS。图片中的母座与板载插座之间需要匹配线束，实际电池尺寸和线束净空留给后续结构设计核实。
