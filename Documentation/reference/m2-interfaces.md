# Motor 外接模块接口

更新日期：2026-11-08。以下描述当前精简电路及 M2.8P 引脚规划，替代旧版的独立步进控电、Maix 理想二极管和荔枝派 Q3 感知方案。[GPIO 分配](motor-core-pins.md)单独维护，[原生原理图](../../Hardware/stm32c5a3/Hardware/CoralC5-Motor/CoralC5-Motor.kicad_sch)为电气依据。

## 板端针序

下表从板端 1 脚开始；TX/RX 网络名以 MCU 方向命名。J15/J17 是 2.54mm 排母；J20/J21/J23 使用普通 XH 座，封装按 JST XH 2.50mm，不是 XHB。商品名 XH254 不能代替实物间距、插接及线束导通检查。

| 位号 | 定义与用途 |
| --- | --- |
| J1 XT60 | 12V/12.5A 整车适配器输入，经 F1 和双 MOS 总开关 |
| J10 两针跳帽 | 1 为 MCU 请求经 R6，2 为 MOTOR_RUN；插帽允许 MCU 控左右轮，拔帽由 R7 拉低停止轮驱动 |
| J15 HC-08 | 3V3_EXT、GND、模块 RXD、模块 TXD；固定 3.3V |
| J17 TFT | GND、3V3_EXT、SCK、MOSI、RES、DC、CS、BL |
| J18 荔枝派信号 | 2×6、2.54mm，按原板针序，见下节 |
| J25 荔枝派电源 | 6 触点 Type-C，5V A 轨，经 U8 接入检测、3A 通告和限流；无 USB 数据 |
| J19 MaixCAM2 | MX1.25 六针卧贴：GND、保护后 5V、NC、NC、模块 TX、模块 RX；接 1/2/5/6 |
| J20 灰度数据 | CH1～CH8，来自 MSPM0L1306 辅助板 |
| J21 灰度电源 | GND、5V_EXT；与 J20 配合使用 |
| J23 ZDT TTL | VM、GND、NC、NC、NC、NC、模块 RX、模块 TX；只用 1/2/7/8 |
| J28 Action 4 | Type-C，5V B 轨，经 U16 接入检测、3A 通告和限流；无 MCU 数据 |
| SW2～SW5 | 模式、下一项、确认、启动；6×6×4.3mm 四脚 SMD 通用封装，脚跨距待实物核对 |
| H1/H2 | 保留两只 TFT 安装孔；本轮不改孔位，装配尺寸须与实屏核对 |

J22/J24/J26/J27 均不在当前设计，不再按旧图接线。J10 仅控制轮驱动，不控制步进或整车总电源。

## 荔枝派 4A

J25 是固定五伏源端，无 PD/PPS 或数据。J18 的 1 脚五伏、2 脚三伏三均留空，电源只走 J25。

| J18 脚 | 当前连接 |
| --- | --- |
| 1、2 | NC，不并联荔枝派电源与 Core 三伏三 |
| 3、4 | GND |
| 5～10 | NC，SPI 与 UART0 不接 |
| 11 | 原板 UART1_RX，通过 U12 接 Core TX |
| 12 | 原板 UART1_TX，1.8V，通过 U11 升至 Core 3.3V RX |

11 脚原板内已有分压，外部按 3.3V 接收使用；不再先降至 1.8V。U11 为 SN74LV1T125DBVR，U12 为 SN74LVC1G125DBVR。两者由 Core 3.3V 供电，OE 接地常使能，已取消 Q3 感知通断。不要将此结构描述为 UART 掉电隔离。Linux 端为 UART1（原资料默认 /dev/ttyS1），Core 端为 USART1，两侧编号不必相同。协议、波特率及上电时序尚需程序与实物验证。

## 步进

套件为 ZDT_XS 第二代 TTL 一体驱动。手册八针顺序为 V+、Gnd、Com、En、Stp、Dir、R/A/H、T/B/L；TTL 版后两针分别是驱动 RX、TX。不是电机线圈端口，不给其输入 Core 三伏三电源。

J23 供电直接来自整车开关后的 VM，串口直连 Core USART6。独立 F2、Q6～Q9、U15 及 STEP_PWR_EN 已删除，PD12 空闲；当前没有 MCU 单独断电能力。预算 3A 是输入预算，不是用线圈相电流代替实测输入电流。上电稳定后再发运动命令，浪涌、再生及温升待实测。

## MaixCAM2 与电源边界

J19:5/6 分别接 VIDEO_RX/VIDEO_TX；这两个旧网络名目前用于 MaixCAM2 识别，Action 4 只接电源。

U10 为 SGM2531CXPS8G/TR，保留 R72 与去耦。ENUV 接输入、OVP 接 GND、SS 悬空，使用当前简化配置；旧版独立欠压/过压分压、软启动电容、U14/Q5 理想二极管、U13/Q4 串口隔离及 J27 已删除。R72=95.3k 对应典型约 0.999A 限流，不能当作全温准确上界。六针座额定 1A，识别叠加内置电池充电的启动峰值未实测。

本板没有独立的输出防反灌或 UART 掉电隔离。Maix 的六针、Type-C 与扩展口五伏在模块内部相通；外接电源使用单一来源，调试不得直接并联第二路带电 VBUS。Core 与模块电源、UART 上电时序仍需检查。

电源保持两路 AP64500：A 轨供荔枝派、Core、灰度与低功耗外设，预算 4.2A；B 轨供 MaixCAM2 与 Action 4，预算 4.0A。均标称 5.088V、500kHz，芯片额定 5A 不代表本板持续输出能力。Core 由 D3 后的 A48/B48 五伏供电，自带三伏三稳压；外设 U7 的三伏三不与 Core 三伏三并联，Core 外接三伏三负载仍限制在 100mA 预算。

整车约 11.09A 的计算采用降压效率 85%、左右轮合计 4A、步进 3A 等假设；12V/12.5A 适配器的启动和持续余量需要实测。元件额定、估算与实测分别看待，当前没有完成温升、启动、稳定性或整车验证。
