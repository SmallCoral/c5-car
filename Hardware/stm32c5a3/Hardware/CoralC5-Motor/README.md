# CoralC5-Motor

2026-11-07，M2.7。[主原理图](CoralC5-Motor.kicad_sch)、[九页 PDF](docs/CoralC5-Motor_Schematic.pdf)。总览、电源、灰度与识别、蓝牙与步进为 A3，其余五页为 A4。

扩展板只有一路 TPS56837RPAR 主降压，标称 4.992V、芯片等级 8A；Core、MaixCAM2、Action 4、灰度共享，TFT 与蓝牙共用 AP2112K-3.3 小 LDO。U6/L2 及外围删除。Core 从 D3 后 A48/B48 取电，其 AP63203 产生 3.3V。Core 的 USB 隔离保留；两个 3.3V 不并联，Core 对外预算仍为 100mA。

MaixCAM2 作识别，J19 改为同型号 MX1.25 六针，1～6 为地、保护五伏、NC、NC、模块 TX、模块 RX。六针座额定 1A，限流公式标称 0.9986A；识别叠加充电可能超出，必须实测。U10 SOIC-8 保护、U14/Q5 防反灌及 J27 保留，带电 USB 调试前拔 J27。

Action 4 作图传，仅接 J28 Type-C 电源。TPS25810 集成接入检测、3A 通告和限流，固定五伏，无 PD/PPS 或 MCU 数据。C81 储能按源端要求保留。四键删 C57～C60，保留上拉，固件需消抖。

步进只保留 J23 普通 XH 8P，1/2 供电、7/8 TTL，3～6 不接。PD12/B30 高有效控电、默认断电，U15 隔离串口。F1 15A 快断、F2 4A 延时保留。五伏总负载按 5.2A、效率按 85% 预算，10V 电池端约 10.054A，尚非实测。
