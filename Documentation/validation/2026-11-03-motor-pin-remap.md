# 2026-11-03 Motor布线检查与引脚调整

源码基点：`0b6e5ea0e0e913346a675242086204cccd8a8c60`，本轮开始时工作区已有用户新布局与走线。
使用本轮开始时的实际文件副本作为比较基线，工具为KiCad CLI 10.0.8及其Python。
检查对象是Motor当前PCB，未改旧项目、Core PCB或网络Expansion PCB。

## 已布部分的检查

两路DRV8874到J4/J6的四条电机功率网络均连通，原生DRC没有报告这些网络的未连接、短路或间距错误。
编码器原始A/B到RC及整形输入的布线已存在，整形输出到J14尚未布出。
电机输出主体线宽0.45mm，左右OUT1各有一个0.5mm外径、0.3mm孔径过孔。

这不等于确认整板可上电。
地平面、PGND/GND/裸露焊盘回流以及主电源尚未全部接通，当前没有铜区。
[TI DRV8874 SLVSF66A](../../Hardware/stm32c5a3/Hardware/CoralC5-Motor/docs/sources/DRV8874_SLVSF66A.pdf)第31页要求VM、OUT1、OUT2和PGND尽可能采用宽铜，PGND/GND接同一地平面，裸露焊盘配合铜面和散热过孔。
较长的电机功率段建议在空间允许时加宽至约0.8～1.0mm或采用铜皮，再按铜厚、实际电流与温升核实；芯片引脚附近可短距离收窄。
单个0.3mm过孔不能仅凭DRC通过就视为验证了持续2A能力，可比较并联过孔或减少换层。
没有擅自改动用户已经完成的功率走线。

## 本次调整

重新分配13个Motor信号，原理图与PCB的J14网络同步。
上方编码器改到PA0/PA1（TIM5），下方改到PB3/PA15（TIM2）。
两路PWM改为PC2/PB8的TIM4_CH4/CH3，电流采样改到PH5/PC0。
完整引脚、触点、相位顺序和布线建议见[分配表](../reference/motor-core-pins.md)。
Core的98触点物理合同不变。
PCB只修改J14的22个焊盘网络，所有器件位置、旋转、已有铜线和过孔保持不变。
旧触点恢复明确NC，新触点的外设能力和资源冲突按原厂表检查。
