# 轮电机使能线路排查

后续状态：用户处理 PA3 附近焊点后，启动时 PA3 已能读到高电平；修正驱动唤醒检查时序后，两轮主动转动已验证。以下保留为同类故障排查步骤。

适用现象：请求轮电机运行后出现 `ENABLE LOW / PA3`，遥测 `wheel_trip=4`。
2026-11-16 实测中，换 J10 跳帽及拔下 J10 后均出现 PA3 输出锁存为高、输入回读为低；具体证据见[联调记录](../validation/2026-11-16-wheel-drive.md)。
这说明 PA3 电平异常，不能单凭寄存器读数断定某个焊点短路或 MCU 已损坏。

## 先检查相邻地脚

断开电池及所有 USB/调试器供电，拔下 J10，再使用电阻档或检查连锡。电机插座的 M− 不是系统地。

| 位置 | 使能端 | 相邻地端 | 优先检查 |
| --- | --- | --- | --- |
| Core 主芯片 U1 | 第 26 脚 PA3 | 第 27 脚 GND | 两脚间连锡、引脚与焊盘桥接 |
| Core 金手指 J13 | B2 / PA3 | B1 / GND | B2 对 B1 电阻、焊锡或异物 |
| Motor 核心板座 J14 | B2 / MOTOR_EN_REQ | B1 / GND | 座底焊点、B2/B1 之间连锡 |

按封装 1 脚标记及 CAD 焊盘编号定位，不按照片左右方向猜引脚号。U1 为 LQFP100，PA3 与地脚关系也可核对 [ST 数据手册](https://www.st.com/resource/en/datasheet/stm32c5a3vg.pdf)。
测 B2 到 B1 的稳定电阻并记录数值；不要仅凭蜂鸣器一声判定短路。若读数接近表笔短接值，断电分离 Core 与 Motor 后分别测两板，定位低阻属于哪一侧。

## 使能线路顺序

```text
Core U1-26 (PA3) ─ J13-B2 ─ Motor J14-B2 ─ R6-1
                                                  R6 = 100 Ω
                                               R6-2 ─ J10-1
                                                      跳帽
                         U2-3、U4-3 (nSLEEP) ───────── J10-2
```

J10-2 是 MOTOR_RUN，另接 R7（10 kΩ）、R14/R34（各 100 kΩ）下拉。
J10 拔下后，正常装配的两侧应隔离；同时检查 J10 焊盘之间有无连锡，以及 R6 两端的连接。
若 PA3 前端没有低阻异常，再比较分离两板前后的输入回读与实际电压，不通过短接到 3.3 V 强行使能。

针脚来自当前 Core/Motor 原生网表与 [98 触点合同](../../Hardware/stm32c5a3/Hardware/Shared/interface.csv)，本轮未修改硬件文件。
