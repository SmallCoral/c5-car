# 校赛 A 题实车基线

2026-11-21，在 Core + Motor 实车上通过 HC-08 采数。各题标注当时的主控应用 CRC32。球位以 O 为零，向右为正。车身停车距离由操作者观察同一参考点估计。

## 第一题 · 从右挡杆起步

主控 `8A10EDEE`，操作者确认起点贴右挡杆。按下 SW2 开始计时，9.948 s 完成。下表“到达”取该段首次采到进入目标 ±10 mm 的直接观测。“停稳”取主控完成该段连续停留的时刻。O 和右点的区间来自相邻两次状态回读。

| 目标 | 首次到达 | 确认停稳 | 规定停留 |
| --- | ---: | ---: | ---: |
| O | 约 3.54 s | 4.067～4.226 s | 0.30 s |
| 右 50 mm | 约 4.95 s | 6.400～6.612 s | 0.40 s |
| 左 50 mm | 约 8.97 s | 9.948 s | 0.40 s |

最长连续失测跨过启动，约 1.20～1.26 s，其中启动后约 0.9 s。左点完成后 10 s 内采到 114 个直接观测，位置在 −52～−46 mm，末值约 −47 mm，比窗口首样本向 O 移动约 3.4 mm。相机在首页约 29.8 帧/s，设备上实跑脚本和模型的哈希待核对。[蓝牙采样](data/task1-right-stop.csv) · [球位轨迹图](data/task1-position.png)

合并固件的回归另用两条历史实车轨迹，分别覆盖起步时有球位和起步时失测，预期完成时间为 5.441 s 和 7.512 s。[回放输入](../../Firmware/tests/fixtures) · [回放断言](../../Firmware/tests/test_position_trace.c)

## 第二题 · 循线停车

主控 `D97DBD0E`，13.203 s 完圈，41800 计数停车。停车后 3 s 收到六帧遥测，两轮速度、PWM 和故障位均为零。现场估计提前 1～3 cm。[结果页回读](data/task2-readback.json) · [停车遥测](data/task2-finish.csv)

## 发挥一 · 右 23 mm

主控 `EC2ED1B4`，停车门槛 42000 计数，实跑 42003 计数，用时 32.468 s，现场估计提前约 1 cm。主控按相机序号统计了行驶期间的 970 个可信球位。误差最小 −17 mm（起跑后 0.853 s），最大 +17 mm（12.536 s），超出 ±20 mm 共 0 帧。最长有效观测间隔 41 ms，最后一个有效观测距完圈 3 ms。

蓝牙抽样收到 288 个行驶直接观测。停车后继续稳球，9.873 s 时球位为右 28 mm，比目标偏右 5 mm。这圈完整 OTA 耗时 88.6 s，DATA 吞吐 828 B/s，重试 13 次。[逐帧统计回读](data/offset-range.jsonl) · [轮速与球位](data/offset-lap.csv) · [固件身份](data/offset-readback.jsonl)
