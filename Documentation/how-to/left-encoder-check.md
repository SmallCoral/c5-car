# 左编码器焊接与测点检查

后续状态：用户重焊后反馈左右编码器均可正常读数。以下保留当时排查路径；当前轮电机使能问题见[PA3/J10 测点](wheel-enable-check.md)。

2026-11-16 首次联调：J10 未插，用户手转右轮时计数变化；左轮计数及 A/B 小点不变化。
固件已启用 PA0/PA1 的 TIM5 编码器模式，读取到的左路电平持续为 A=1、B=0。
这说明当前没有收到有效的左路变化，尚不能仅凭软件确定是焊接、接触、线束还是编码器问题。

以下针号已对照当前 Motor PCB 焊盘网络、Core 网表及[六针接口约定](../reference/motor-interface.md)。
位置编号以器件 1 脚标记、连接器方焊盘/图纸为准，不能从照片左边开始数。

## 先查供电和地

先停止步进，断开电池及 USB 等所有供电，再检查虚焊、翘脚和连锡。
测电压时重新供电，保持 J10 不插；黑表笔接系统地。

| 测点 | 预期 |
| --- | --- |
| J4-2 对 J4-5 | 编码器供电约 3.3 V |
| U3-5 对 U3-2 | SN74LVC2G17 供电约 3.3 V |
| C19 两端 | 100 nF 去耦，同一组 3.3 V 与地 |

J4-1 是 H 桥电机输出，不是地。不要将 VENC 或 Core 的 3.3 V 网络改接 5 V。

## 两路信号路径

| 部分 | A 相 | B 相 |
| --- | --- | --- |
| 六针座输入 | J4-3 | J4-4 |
| 串联电阻 | R16-1 → R16-2，1 kΩ | R17-1 → R17-2，1 kΩ |
| U3 输入 | 1 脚 | 3 脚 |
| U3 输出 | 6 脚 | 4 脚 |
| 扩展板 98P 接口 | J14-A4 | J14-A3 |
| 核心板触点 | J13-A4 | J13-A3 |
| STM32 U1 | 23 脚 PA0 | 24 脚 PA1 |
| 输入上拉 | R18，10 kΩ 至 3.3 V | R19，10 kΩ 至 3.3 V |
| 输入滤波电容 | C17，1 nF 至地 | C18，1 nF 至地 |

断电用电阻档/通断档逐段检查：J4-3 到 R16-1、R16-2 到 U3-1、U3-6 到 J14-A4；B 相同理。
R16/R17 两端是约 1 kΩ，不要求蜂鸣；在板测阻可能受其他支路影响。
U3 输入和输出间经过逻辑芯片，**U3-1 与 U3-6、U3-3 与 U3-4 不应按一根导线测通断**。
板间触点与 MCU 焊脚也要检查，尤其 U1 相邻的 23、24 脚是否连锡。

U3 为双路同相施密特缓冲器，1→6、3→4；2 脚地、5 脚电源，见 [TI 引脚定义](https://www.ti.com/lit/ds/symlink/sn74lvc2g17.pdf)。
辨认 1 脚后再编号，U3 在本 PCB 中有旋转放置，不能照屏幕朝向猜脚号。

## 上电手转时定位

保持 J10 不插，缓慢分段转动并停住车轮，观察电平；有示波器或逻辑分析仪时可直接观察 A/B 波形。
普通万用表在持续快速转动时可能只显示平均电压，不能据此认定没有脉冲。

- J4-3/4 就没有变化：检查六针座焊点、线束压接、编码器供电与编码器本体。
- J4 有变化、U3-1/3 没有：查 R16/R17、C17/C18 连锡/短路及这段走线。
- U3 输入变化、输出不变：查 U3 的方向、型号、供电与六脚焊接，再判断芯片是否损坏。
- U3-6/4 有变化、主控 PA0/PA1 没有：查 J14/J13 的 A4/A3 接触、核心板走线及 U1-23/24 焊点。

同类右路 U5 可作电压与波形对照。需要进一步隔离时，断电对换 J4/J6 的电机线束，再手转比较故障是否跟随线束。
