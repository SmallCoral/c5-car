## 参考代码能证明的内容

同学 `26H` ZIP 的公共路径为 `26H 平衡球装置 F407/26H_F4 _Speed_now/`，原件保留在 [归档](<../26电赛/26H 平衡球装置 天空星F4.zip>) 中。

- `Maxicam/maxicam.c` 第 76～77 行解析 X/Y 坐标；`Core/Src/usart.c` 的 USART2 为 115200、8N1，这是旧 F407 工程配置。
- `step_motor/motor_X.c` 有 Emm 位置、速度、回零及反馈处理，使用旧工程 USART3。现有四线步进的铭牌记录和线圈定义见 [电机接口](motor-interface.md)，不据 Emm 示例推定实物已安装 Emm 驱动。
- `XunJi/Xunji.c` 第 310～317、356～367 行读取 8 路 GPIO，并将黑线低电平作为有效检测。它与八路数字接口相符，但不能据此推定辅助板插座针序或电压。

五个电赛归档中未找到可识别为相机端视觉应用的 Python 文件；其中 M0 SDK 的 `mcuboot` 脚本属于构建工具。图传没有单独资料包。灰度的厂商包由用户本轮补齐。

本轮只整理资料和确认接口类别，没有修改原理图、PCB、生产 BOM、固件或整车 CAD；参考代码未编译、烧录或实测。核对记录见 [2026-11-06](../validation/2026-11-06-external-modules.md)。
