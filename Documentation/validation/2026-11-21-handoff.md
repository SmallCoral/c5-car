源工作区基于 Git `83bb6c0`。第一题源码从两次第二题改动前的备份还原，核验标签提交为 `1a33297`。构建工具为 CMake 4.3.1、Arm GNU 14.3.1、主机 GCC 15.2.0、Python 3.12.14。下列命令从仓库根目录运行，主机测试时将 MinGW GCC 放在 PATH 中。[两版固件的完整哈希](../../Firmware/releases/README.md) · [相机版本与历史同图回放](../../Firmware/26h/README.md)

```powershell
cmake --preset debug -S Firmware -B .scratch/verify-debug
cmake --build .scratch/verify-debug
cmake --preset release -S Firmware -B .scratch/verify-release
cmake --build .scratch/verify-release
cmake -S Firmware -B .scratch/verify-host -G Ninja -DHOST_TESTS=ON -DCMAKE_C_COMPILER=gcc
cmake --build .scratch/verify-host
ctest --test-dir .scratch/verify-host --output-on-failure
python -m unittest discover -s Firmware/tests -p 'test_*.py'
```

完成核验时已将本机固件 Python 虚拟环境重新关联到现有 3.12.14 解释器。最初手写的工具链参数未解析为完整路径，改用仓库自带的 CMake preset 后两个 ARM 配置均成功。此次固件核验均在电脑端完成。
