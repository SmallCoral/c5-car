# MG513 六针电机接口

更新时间：2026-11-03。
本表是当前 Motor 的 J4（左）、J6（右）六针线序的唯一维护入口。

## 实物依据

现有轮电机是 WHEELTEC `MG513XP28_12V`。
旧项目 `docs/电机/ACG720与现有电源板接线_2026-10-10.md` 第“实物电机照片确认”节记录过电机丝印及线束对应关系。
原记录中，电机尾板照片自上而下为电机+、编码器GND、B、A、编码器5V、电机−。
对应旧板连接器编号自 6 到 1。
本次沿用该板端编号关系，不依据线色重新猜测。

| 板端针号 | 信号 | Motor 新原理图连接 |
| --- | --- | --- |
| 1 | 电机− | 左侧U2／右侧U4的DRV8874 OUT2 |
| 2 | 编码器电源 VENC | 当前仍为 Core 的3.3V |
| 3 | 编码器A | 1k/1nF及 SN74LVC2G17 输入A |
| 4 | 编码器B | 1k/1nF及 SN74LVC2G17 输入B |
| 5 | 编码器GND | 系统GND |
| 6 | 电机+ | 左侧U2／右侧U4的DRV8874 OUT1 |

这是电气编号，不是“照片左边起数”规则。
用连接器图纸的1脚位置及线束导通确认实物方向。
M+/M−是电机端标识，H桥两端均为受控输出，不能把M−当作系统地。

## 本轮修改

原先每侧是两针功率端子加四针编码器座，电气功能齐全，但不能直接容纳原装六芯线束。
现在左右电机统一使用J4、J6六针口，动力与编码器共用同一插座。
2026-11-03按要求删除J3、J5的原理图器件、PCB封装及仅通向这些端子的PCB支线。
当前PCB的J4、J6已经是六针封装，本次保留其位置、旋转及网络。
当前检查见[端子删除记录](../validation/2026-11-03-remove-j3-j5.md)。

库封装采用 JST XH `B6B-XH-A(LF)(SN)` 的2.50mm垂直六针外形。
同类国产 XH2.54 或 PH2.0 不能只凭商品名称判定兼容。
旧文字记录证明六线信号顺序，不足以证明当前插壳的精确间距、锁扣和1脚方向。
正式采购前测量现有插壳并确认插接；不匹配时更换对应座或压制转接线。

## 电平与编码器版本

历史照片的编码器电源印5V，系列资料允许3.3～5V，但本批次3.3V工作尚未验证。
本次保持原供电网络，不把Core整条3.3V网改成5V。
M2可增加独立VENC选择，但必须同时核查电源隔离、上拉和输入容限。
现有LVC缓冲器应按[TI资料](https://www.ti.com/lit/ds/symlink/sn74lvc2g17.pdf)复核5V输入与掉电行为。
Core对全部外接3.3V负载的100mA预算仍适用。

10月10日实物记录支持霍尔编码器版本。
若每电机轴13周期、减速比28，输出轴AB四倍频的理论计数为1456。
实际每圈计数和左右方向仍须实测，不把系列值写死为校准结果。
如果换成500PPR的GMR版本，需要重算最高边沿频率和RC滤波，不能直接沿用霍尔设置。

## 四线步进电机

现有普菲德 `42BYGH34-401A` 铭牌为1.8°、1.5A、0.28N·m。
黑A+、绿A−、红B+、蓝B−；上电前用导通再次确认线束。
该四线是两组线圈，需要独立双H桥恒流步进驱动，不能接轮电机的六针口。
摆杆方案拟用一台，另一台不列入A题必需用料。
