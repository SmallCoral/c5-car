# 视觉板与摄像头接口

2026-11-07 M2.8：**荔枝派 4A、MaixCAM2 与 DJI Osmo Action 4 均保留**。MaixCAM2 识别经 J19 同序六针，只接 1/2/5/6，额定 1A，保留保护和防反灌。Action 4 图传由 B 轨 J28 Type-C 供电，荔枝派由 A 轨 J25 Type-C 供电，两口固定五伏、3A 通告，无 PD/PPS。荔枝派 J18 原板针序 UART1 经电平处理连接 Core USART3；具体应用职责与通信协议未实现。详见 [接线](m2-interfaces.md)和 [M2.8 验证](../validation/2026-11-07-m28-resume.md)。

荔枝派电源及串口已恢复；MaixCAM2 的识别职责保留。机械模型尚未按这三个模块的实际外形重建，旧夹持包络与孔位不能直接用于加工。

以下为 2026-11-05 的旧机械布局参考，**MaixCAM 首代与 OV2640 的参数不适用于新组合**。机械模型本轮没有重建，旧夹持包络、视场及孔位不能用于 MaixCAM2 或荔枝派的加工。

## 历史双摄方案

2026-11-05。用户确认有两只摄像头，检测端为 **MaixCAM**；项目原有图传方案为 **OV2640 + ESP32-S3**。本轮仅落实机械装配，尚未新增电路、识别固件或已实现功能。

## 本轮支架

共享升降方管和悬臂，上方设置两个独立调角座。MaixCAM 的图像长边规划沿 280 mm 球槽，镜头垂直向下；图传镜头位于其侧方约 50 mm，向球槽倾斜约 12°。两只镜头错开，横梁位于其背面。

MaixCAM 夹持包络暂画 65×45×23 mm，OV2640 模块包络暂画 36×26×1.6 mm。这些数值是本轮**可调支架的布局假设**，不是找到的原厂整机尺寸。镜头凸出、装配间隙、具体孔距、接口避让和夹持软垫仍待实物核对。

默认检测相机镜头约高于底板 309 mm，高于零角度球槽约 219 mm；立柱提供下降 60 mm、上升 30 mm 的构型余量，夹持及抗振能力尚未实测。按官方视场角所做的覆盖计算，只在对应镜头、方向和无裁剪取流条件下成立，不代表钢球识别已经通过。

图传处理板另留近端托盘，避免假定长距离裸 DVP 排线可以稳定工作。当前小板也只有空间占位。
