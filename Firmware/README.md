# STM32C5A3 比赛固件

实车使用 C/LL 合并应用。上电进入校赛首页，从左到右为 SW5 返回、SW4 上一项或向左、SW3 下一项或向右、SW2 进入或启动。每次确认后松开 SW2，再按才会触发下一步。第一至第四题和发挥一均可从首页操作，发挥二保留菜单入口。

实物水平对应步进驱动的单圈编码值 **10832**。收到回水平请求时，主控根据同一帧的单圈与多圈读数，选择最近的等效水平位置并锁定目标，最多转半圈。首次进入、换题、重试和调试页 `C5:LEVEL` 共用这套定位。原安装角度的电子限位已取消。手动标定页仍可用 SW4、SW3 点动。

## 第一题 · 停车移球

各稳球题启动时先确认水平，再以 45 rpm 一次下发 −12° 轴角抬起右端。编码器确认到位、球心向管内越过 34 px 并取得连续两帧可信观测后，进入移球闭环。找球期间两轮关闭。

第一、三、四题和发挥一共用位置与速度反馈。需要低速穿过 O 且到目标还剩至少 20 mm 时，向左一次给到 −22°，向右给到 +17°，定位速度为 75 rpm。快抬最多 300 ms，随后恢复速度制动。发挥一原地选左点时，如果球连续 0.6 s 困在 O 附近，会尝试一次先到右 50 mm 再向左移球。车轮起跑或操作者改点时撤销这个临时动作。

进入第一题，等屏幕显示 `LEVEL OK`。再按 SW2 开始计时，车轮保持静止，球依次移到 O、右 50 mm、左 50 mm。规定停留分别为 0.30、0.40、0.40 s。停留时球须在目标 ±10 mm 内，且同一停留段的位置跨度不超过 4 mm。8 s 后继续到左点，完成后维持闭环。预测帧不能单独确认到位。[停稳计算](src/contest.c) · [实车计时](../Documentation/validation/README.md)

## 第二题 · 循线停车

在 A 线对准车身参考点，车头朝顺时针。进入第二题，SW3 可换档，SW2 起跑。默认直道目标为 4600 编码器计数/秒，弯道上限 3100。起步先直行，连续 100 ms 检测到 1～2 路纵线后开始识别终点。此后 4～5 路灰度探头连续压黑至少 10 ms 即停车。轮编码器仍反馈车速，并按预计 41800 计数安排最后 900 计数的减速。[场地操作与保护条件](../Documentation/how-to/line-following-lap.md)

## 第三题和第四题 · 在 O 点稳球循线

把车身参考点对准 A 线，车头朝顺时针。按 SW2 进入所选题目，再按 SW2 原地稳球。长度条显示实测球位和 O 点目标。等屏幕显示 `SW2 RUN`，再按一次 SW2 开始行驶计时。两题均持续调管倾角，目标为 O 点，赛题允许偏差 ±20 mm。正常到终点后车轮停止并继续稳球，行驶超时、持续丢球或循线故障会保护停车。

| 题目 | 路线 | 行驶时限 | 停车依据 |
| --- | --- | --- | --- |
| 第三题 | 从 A 沿 1.5 m 直线到 B，停车 | 12 s | 双轮平均 10257 计数，按整圈 6142 mm、42000 计数折算。最后 2500 计数平滑降速，全程按灰度纠偏。B 点待实车复核 |
| 第四题 | 从 A 顺时针一圈回 A | 40 s | 与第二题共用 A 标记判停，按 42000 计数规划减速 |

## 发挥一 · 定点稳球

1. 在 A 点选中发挥一，按 SW2 进入选点页。SW4 向左、SW3 向右，短按 1 mm。按住 0.40 s 后每 50 ms 连调 1 mm。按当前挡杆标定可选 −107～+93 mm，赛题指定范围为 −50～+50 mm。
2. 再按 SW2 开始原地稳球。此时两个选点键仍有效，目标会随按键更新。长度条上绿色箭头表示目标，黄色实心点表示实测球位，空心点表示最近一次观测。[长度条预览](../Documentation/validation/data/ruler.png)
3. 球稳好、屏幕显示 `SW2 RUN` 后再按 SW2，锁定目标并起跑。巡航目标为 1400 计数/秒，接近预计的 42000 计数时，在最后 2500 计数内降至 450 计数/秒。回到 A 标记按第二题相同的灰度条件停车，随后继续按原目标稳球。行驶中持续 0.50 s 缺少可信球位会停车。[轮速与球位实测](../Documentation/validation/README.md)

## 球位标定与长度条

左挡杆、左 5 cm、O、右 5 cm、右挡杆对应的原图球心为 **521、388、253、128、24 px**。控制器、屏幕球心和目标刻度共用同一组坐标。[实测标定记录](calibration/camera640-and-shaft.json)

## ASR PRO 语音操作

V3 语音桥使用 `BALL-V3-DUPLEX-CCCD2`。ASR PRO 与 ESP32-S3 之间是 9600 波特，本车 HC-08 与 STM32 USART1 之间是 **57600 8N1**。ESP32 按车上地址 `F8:2E:0C:F3:68:37` 连接，发现 `FFE0/FFE1` 并订阅通知，再用 `C5:INFO` 核对主控身份。看到 `BLE READY: duplex HC-08, STM32= ...` 后即可说「题目一」。在连接 ESP32 的电脑用 Thonny 打开脚本、按 F5 即可试运行。电脑监视器用完后断开车上的 HC-08 连接。[ESP32 语音桥](voice/xiaosai.py)

| 口令 | 小车动作 |
| --- | --- |
| 题目一 | 开始 O、右 5 cm、左 5 cm 移球，车轮静止 |
| 题目二 | 从 A 启动循线，开始前对准起点 |
| 题目三、题目四 | 先原地稳在 O。显示 `SW2 RUN` 后说「继续」或按 SW2 起跑 |
| 发挥一 | 开始稳球，用 SW4/SW3 调整目标，随后说「继续」或按 SW2 锁定目标并起跑 |
| 发挥二 | 显示「控制待接入」 |
| 继续（`37 0A`） | 当前载球任务满足起跑条件时继续，累计最大偏差保留 |
| 退出（`38 0A`） | 停车、返回首页并保持步进。主控回传有实测数据的本题最终最大偏差 |

例如「题目三」发送 `S,42,3\n3\n`，其中 42 由 ESP32 分配，`\n` 表示一个 LF 字节。题号匹配后启动，同一次会话重复发送题号会被忽略。上电后可直接使用旧数字协议。收到 V3 退出命令 1.5 秒后，旧语音桥也可只发数字切题。

第一、三、四题和发挥一逐帧统计可信实测球位与当时目标的差，单位为毫米，向右为正。找球、移球、调点和行驶中的有效观测均计入当次会话。第一题的目标随 O、右 50 mm、左 50 mm 切换。每 200 ms 最多发送一行 `D,42,-3\n`。说「退出」后发送 `F,42,5\n` 形式的全程最大绝对偏差。纯循线、尚未接入的题目或全程无有效球位时没有数值可播。ESP32 的 `UNIT_CODE=1` 可播出「毫米」。

## 构建与回归

需要 CMake ≥3.22、Ninja、Arm GNU 工具链、主机 C 编译器和 Python ≥3.10。实车镜像用 Arm GNU 14.3.1 的 Debug 配置构建。以下命令从 `Firmware` 目录执行，Windows 可把 MinGW 的 `bin` 加入当前终端 PATH。

```powershell
cmake --preset debug
cmake --build build/debug --target competition_image
python -m unittest discover -s tests -p "test_*.py"
```

`competition_image` 生成 `build/debug/coral_c5.ota`，检查最终链接的比赛入口，并运行主机 CTest，含实车轨迹回放。构建 Release 使用 `cmake --preset release` 和 `cmake --build build/release --target firmware_package`。单独查看回归结果可运行 `ctest --test-dir build/host --output-on-failure`。

本车机构允许解除步进抱持。从仓库根目录运行 `./Firmware/flash-wireless.ps1 -PipeSupported` 即可构建、回归并无线更新。应用区起始地址为 `0x08010000`。需要在更新时保留步进抱持，可在仓库根目录运行 `./Firmware/flash-jlink.ps1`。默认脚本会回读校验应用与镜像头，再让新应用接手抱持。[升级步骤](../Documentation/how-to/wireless-update.md) · [镜像恢复与校验](releases/README.md)
