# 2026-11-03 删除J3与J5

范围：Motor原理图及PCB的J3/J5两针电机端子。
工具：KiCad CLI 10.0.8、KiCad随附Python。
源码基点仍为 `0b6e5ea0e0e913346a675242086204cccd8a8c60`，工作区已有用户修改。
实际基线采用本次删除前的最新文件副本，不还原Git版本。

## 修改

- 删除左电机页J3、右电机页J5及通向端子的原理图末端线段。
- 保留两片DRV8874到J4/J6六针口的连接。
- 删除PCB上的J3、J5封装及通向J3的六段独立支线；其余PCB对象逐项完全相同。
- 保留用户最新保存的六针J4/J6，包括其位置、旋转、焊盘和模型。
- 同步当前BOM、设计清单、接口表、检查合同和五页原理图PDF。

## 命令

```powershell
$motor = 'Hardware/stm32c5a3/Hardware/CoralC5-Motor'
$cli = 'D:/KiCad/10.0/bin/kicad-cli.exe'
& $cli sch export netlist --format kicadxml --output "$motor/docs/netlist.xml" "$motor/CoralC5-Motor.kicad_sch"
& $cli sch erc --format json --exit-code-violations --output "$motor/docs/erc.json" "$motor/CoralC5-Motor.kicad_sch"
& 'D:/KiCad/10.0/bin/python.exe' -B "$motor/tools/verify_schematic.py"
& $cli pcb drc --format json --schematic-parity --refill-zones --output "$motor/docs/drc.json" "$motor/CoralC5-Motor.kicad_pcb"
```

ERC和完整合同命令预期返回非零，原因是实际保留的问题。
DRC只生成报告，不保存重新填充后的PCB。
