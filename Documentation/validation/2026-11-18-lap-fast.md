## 速度与纠偏

| 从 A 顺时针起步 | 稳定档 | 新默认档 |
| --- | ---: | ---: |
| 直道目标，CPS | 3300 | 4600 |
| 半圆弯目标，CPS | 2200 | 3100 |
| 单轮目标上限，CPS | 3500 | 4800 |
| 单轮 PWM 上限 | 45% | 60% |
| 加速斜率，CPS/s | 3200 | 4300 |

两处半圆分别以 0 和 21500 编码器计数为参照。新档在各自的 9300 计数开始收速。第一版随后将基础半轮速差逐步加至 23%。两圈实测均在入弯约 12500～14000 计数处偏到 CH3 一侧，随后第一弯约 16000 计数处又反摆向最右端。修正版用连续插值描述两处弯道的差速。两个弯口的基础半差速约为 13%～16%，第一弯中段提前增加到 33%，第二弯中段约 23%。灰度与双轮编码器仍每个周期修正这项基础差速。偏出中心越多，额外巡航速度越小。单轮接近上限时先降低共同速度，保留纠偏余量。[两圈遥测](../../Firmware/validation/2026-11-18/lap-fast/track-1.csv)、[参数](../../Firmware/include/config.h)、[控制实现](../../Firmware/src/lap.c)

普通窄线起步和 MAP B 依靠灰度判弯。高档在这两种情况下更快地建立或撤回差速，并随所需差速增加提前收速。识别 A 后起步目标最高 800 CPS，39000 计数后接近 A 的目标最高 1100 CPS。SPD 可直接选回 3300 档。[操作说明](../how-to/line-following-lap.md)

## 构建与模型

本轮源码以稳定标签为基线。工具为 CMake 4.3.1、Ninja 1.13.2、主机 GCC 15.2.0、Arm GCC 14.3.1、Python 3.12.14。主机测试使用 CLion 的 MinGW bin。可从仓库根目录执行以下命令。

```powershell
cmake --build Firmware/build/host
ctest --test-dir Firmware/build/host --output-on-failure
& .scratch/firmware-tools/Scripts/python.exe -m unittest discover -s Firmware/tests -p 'test_*.py'
cmake --build Firmware/build/debug
cmake --build Firmware/build/release
./Firmware/flash-wireless.ps1
```

CTest 6/6、Python 16/16 通过。修正版共通过 432 组模型。3300、4600 两档各 180 组，另为高速档加入编码器尺度 ±2% 的 72 组完整赛道。3300 档的 180 组与存档逐项对照，停车状态、横向偏差、摆幅、居中率、丢线时长全部一致。4600 档在标称轮距、正常驱动力模型中的直道均速为 4204～4392 CPS、弯道为 2963～3032 CPS。包含里程尺度偏差的 108 组高速整圈均识别 A，最差工况居中率 77.2%。另有转向、丢线停车、起步、按键选档及接近 A 降速的单元测试。[CTest](../../Firmware/validation/2026-11-18/lap-fast/ctest-final.txt)、[完整模型工况](../../Firmware/validation/2026-11-18/lap-fast/model-final.txt)、[修正版源码与镜像散列](../../Firmware/validation/2026-11-18/lap-fast/source-manifest.json)
