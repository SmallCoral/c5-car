# Emm V5.0 闭环步进参考资料

本资料包随同学的历史代码提供，包含厂家说明、示例、工具及模型。
本页是新增阅读索引，原始文件保留原样。
总入口见[同学资料索引](../reference/classmate-materials.md)。

## 说明与协议

| 文件 | 内容 |
| --- | --- |
| [Emm V5.0 步进闭环驱动说明书 Rev1.3](说明书/Emm_V5.0步进闭环驱动说明书Rev1.3.pdf) | 66 个 PDF 页面；产品、安装校准、脉冲及通讯控制、回零、反馈和故障说明 |
| [Modbus-RTU 指令说明](说明书/Modbus-RTU指令说明.pdf) | 30 个 PDF 页面；寄存器、读写格式、运动、状态和回零命令 |
| [新增功能说明](说明书/Emm42_V5.0新增功能说明.txt) | 该资料版本附带的新增功能记录 |
| [通讯校验算法](说明书/Emm_V5.0通讯校验算法.txt) | 通讯校验方式参考 |

说明书区分脉冲控制和串口 TTL、RS232、RS485、CAN 通讯，并列出速度、位置、回零和反馈查询。
这些描述属于所附资料版本，不证明手头电机已安装相应驱动或总线模块。
自定义协议与 Modbus-RTU 是不同的组帧方式，也不与 TMC2209 UART 通用。
