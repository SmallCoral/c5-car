# Motor M2 当前资源与集成范围

2026-11-06 原理图更新至 M2.4，蓝牙固定接外设三伏三，J16 选择跳帽已删除，J10 保留两针硬件使能跳帽。步进已确认采用 ZDT_XS 第二代 TTL 驱动与电机一体套件，预留八针接口；两路摄像头采用处理模块的电源与串口接口。此前板载 TMC2209、ESP32-S3、OV2640 DVP、AS5600 和光栅属于历史候选，本轮没有集成这些电路。

九页包括一张 A3 总览及八张 A4 功能页：入口电源、核心接口、左右电机、独立外设电源、TFT 与按键、灰度与双摄、蓝牙与步进接口。原 13 路轮控制分配保留，新增 31 路 GPIO；98 触点合同不变。

| 资源 | 当前分工 |
| --- | --- |
| TIM5 / TIM2 | 左右编码器 |
| TIM4 CH4 / CH3 | 左右轮 PWM |
| TIM1 CH1 | 外置步进 STEP |
| TIM3 CH1 | TFT 背光 PWM |
| SPI1 | TFT SCK/MOSI，另有 CS/DC/RES |
| USART2 | HC-08 |
| USART3 | MaixCAM |
| USART6 | 图传处理模块 |
| USART1 | 外置步进驱动 UART |
| 灰度 | 八路数字输入，或独立 CLK/DAT，择一接线 |
| 按键 | 四路低有效输入，10k 上拉与 100nF 滤波 |

PB6/PB7 已用于 USART1，不能再按旧规划当 I²C1 使用。PA9 有 Core USB 检测电路，PA11/PA12 为 USB，PA13/PA14 为 SWD；PE3、PD2、PH2 等既有专用脚保留。

五伏外设采用独立 AP63205，预算 1.5A；三伏三外设采用 AP2112K，预算 150mA。Core 三伏三外接预算仍为 100mA。主路已按约 8.32A 的低压端保守预算重新选 MOS，F1 为 12A 延时保险，F2 为 4A 延时步进分路保险；峰值、热设计与电池故障电流仍待实测。

完整针序、GPIO 与触点见 [M2 接线表](m2-interfaces.md)。[最新验证](../validation/2026-11-06-m23-power-connectors.md)包含电流计算、实际检查及未验证项。固件、PCB 和实物均没有因原理图完成而视为完成。
