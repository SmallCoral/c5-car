# 八路灰度联调

适用 C/LL 固件与感为八路灰度＋MSPM0L1306 辅助板。C5 读取 J20 的八路数字量，J21 供电；CLK/DAT 不接。
本页检查灰度采集和通道偏差，车辆尚未使用这些数据自动转向。

## 打开观察页面

1. 保持车辆停止。按最右侧 TASK 循环选择 GRAY；默认上电为 LAP。如果正在运动，第一次按键只停止，再按 TASK 切页。
2. 按 PWR 位置的 B/W 键切换目标：BLACK 为黑线，WHITE 为白线。上电默认 BLACK。
3. 观察顶部 1～8 通道，绿色表示滤波后命中当前目标。RAW 从左到右也是 CH1～CH8，原始白 1、黑 0。

GRAY 页的 VIEW、DIR 均不发起运动。离开页面后其他电机任务仍需按 RUN 启动。

| 显示 | 含义与处理 |
| --- | --- |
| WAIT | 尚未取得每路三次一致的样本，等待输入稳定 |
| NO LINE | 没有命中目标，POS 无效；检查底色、距离、目标极性和校准 |
| LINE | 单段目标，POS 有效；通道 4/5 同时命中时为 0 |
| ALL | 八路都命中目标，POS 无效；不能直接当作居中或路口 |
| MULTI | 有多段目标，POS 无效；不能将多段平均成居中 |

`N` 为命中通道数，`GROUP` 为连续目标段数。滤波要求每路连续三次相同，采样间隔至少 2 ms，屏幕约每 200 ms 更新。
POS 是通道坐标：左侧 CH1=-3500，右侧 CH8=+3500，相邻通道相差 1000；它不是毫米。
2026-11-17 用户完成黑白校准；进一步在主控屏幕核对发现旧程序最左探头点亮 8，线束接入 C5 后反序。当前程序使用 `GRAY_REVERSE_CHANNELS=1`，反序后按实车左 1、右 8 解释偏差，不能以辅助板丝印替代主控显示核对。

## 校准并核对线序

1. 固定最终安装高度和角度，准备实际跑道材质的白场、黑场。
2. 按辅助板丝印操作：长按 KEY 约 4 秒，灯快闪后松开，随后在白场和黑场分别短按完成校准。参见[原厂资料与照片](../感为八路灰度资料/README.md#黑白判定与校准)。
3. 在 BLACK 模式把全部探头置于白场，确认 RAW 为 `11111111`、N=0、NO LINE；置于黑场，确认 RAW 为 `00000000`、N=8、ALL。
4. 用窄黑纸逐个覆盖探头，复核左端 CH1、右端 CH8。单独命中 CH1 时 POS=-3500，CH8 时 POS=+3500；改变安装方向后重新确认。
5. 将黑线放在中间，确认 CH4/5 命中时 LINE、POS=0；移动黑线，确认目标通道和偏差连续变化。

如整排不变，先检查辅助板供电、共地、J20 方向、本体与辅助板连接及校准。软件无法仅凭恒定 `00`/`FF` 区分全黑/全白、未校准或线路故障。
改变高度、更换本体后重新校准；C5 不通过 J20 保存辅助板的阈值。

## 通过蓝牙记录

在项目根目录运行（其他 BLE 客户端先关闭）：

```powershell
.scratch/firmware-tools/Scripts/python.exe Firmware/tools/monitor.py --ble F8:2E:0C:F3:68:37 --gray --seconds 30 --out grayscale.csv
```

`--gray` 先停止电机并切换页面，再保存遥测；本机解释器路径见[无线升级说明](wireless-update.md#上传已有文件或换电脑)。
终端的 `gray(CH1..8)` 按通道顺序显示原始电平。CSV 掩码按十进制存储，bit0 对应 CH1；状态码见[遥测参考](../reference/firmware-telemetry.md)。

构建并无线更新使用 `./Firmware/flash-wireless.ps1`。本轮验证和未完成项见[2026-11-17 记录](../validation/2026-11-17-grayscale.md)。
