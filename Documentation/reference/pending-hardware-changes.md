# Motor 后续硬件变更清单

记录日期：2026-11-05。
来源：本次对话提出的功能需求。
当前状态：只记录，暂不修改原理图、PCB、生产 BOM 或固件。
当前任务优先自行设计小车 3D 框架，复用用户指定的 EdgeMind 编码轮组、万向轮及电池定位框；Motor 机械规划尺寸为 99×99 mm。首版见 [机械模型](../../Mechanical/README.md)。

## 已提出的变更

| 项目 | 已确定需求 | 后续仍需确定 |
| --- | --- | --- |
| TFT 显示屏 | 使用项目已有中景园 `ZJY180S0800TG01`，用于任务选择界面和状态显示 | 安装朝向、支架、排线/线束、背光控制、电源及 GPIO 分配 |
| 操作按钮 | 增加若干按钮用于任务切换及操作 | 按钮数量、确认/返回/启动等具体分工、安装方式和引脚 |
| 蓝牙 | 增加四脚 `HC-08` 模块接口 | 实物版本、四脚针序、电源与 UART 电平、安装位置和通讯用途 |

TFT 型号依据[现有模块规格书](../中景园ZJY180S0800TG01技术资料/01-规格书与控制芯片手册/ZJY180S0800TG01.pdf)。
资料列出 ST7735S 驱动、128×160 像素、四线 SPI，以及 35×56×3.50mm 最大外形。
资料中的八脚定义为 GND、VCC、SCL、SDA、RES、DC、CS、BL；这只是模块资料定义，尚未分配 Core 触点。
机械支架和插针突出量仍需按实物及机械图核对。

四脚 HC-08 没有在本轮锁定具体底板版本或方向，不能据通用商品图写死针序和供电。
通讯用途尚未定义，后续随控制方案确定。

## 当前设计状态

上述三项尚未绘入 Motor 电路，没有接入当前固件或生产 BOM。
首版机械模型按屏幕规格书预留外形，暂画 4 个按钮及 HC-08 安装空间；这些占位不锁定按钮数量、模块实物尺寸或电路针序。
原有 98 触点合同和电机六针定义继续分别以共享接口表及电机接口文档为准。
正式实施时再保存实际设计基线，完成资源分配、原理图变更、原生网表、ERC 与合同检查。
PCB、机械配合和实物验证分别记录。
