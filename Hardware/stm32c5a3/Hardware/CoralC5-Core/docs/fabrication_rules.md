# Core 打样间距规则

2026 年 10 月 23 日按嘉立创公开工艺能力调整，适用于双层 FR4、1.6mm、外层 1oz 铜厚。此次只修改工程规则，没有移动器件、过孔或走线。

| 检查对象 | 当前设置 | 保存位置 |
| --- | --- | --- |
| 过孔铜环到其他铜 | 0.15mm | CoralC5-Core.kicad_dru，仅对含过孔的对象对生效 |
| 孔边到其他铜 | 0.20mm，原为 0.25mm | 项目约束 min_hole_clearance |
| 过孔孔边到孔边 | 0.20mm，原为 0.25mm | 项目约束 min_hole_to_hole |
| 有铜插件孔参与的孔边间距 | 0.45mm | CoralC5-Core.kicad_dru，保留插件孔的较大要求 |
| 其他普通铜间距 | 0.20mm | 原 Default 网络类，保持原样 |

现有过孔的外径和孔径没有修改，仍为 0.50/0.30mm 或 0.60/0.30mm。原有最小线宽、过孔尺寸、板边间距和 DRC 严重级别也保持原样，没有增加 DRC 排除项。

依据 [嘉立创当前 PCB 工艺能力表](https://www.jlc.com/portal/vtechnology.html)，FR4、1oz 的线路与焊盘间距能力为 0.10mm，过孔孔边间距为 0.20mm，有铜插件孔孔边间距为 0.45mm。本工程过孔铜环间距选择 0.15mm，保留一定裕量。

[旧制造工艺要求页](https://www.jlc.com/portal/1/serviceGuide)仍列过孔孔边距 0.254mm，本次采用当前能力表的 0.20mm。无铜孔周围需留出 0.20mm 铜间距。

USB-C 的 J2 原先两处定位孔到 GND 焊盘约为 0.1944mm。2026 年 10 月 23 日晚已将相邻地焊盘的圆角半径由 0.15mm 增至 0.30mm，孔位、0.65mm 孔径和焊盘外尺寸保留，间距约为 0.233mm，四条孔距错误已消除。工程的 0.20mm 阈值保持原样，详见 [PCB 复查记录](pcb_review.md)。C9 与 PA4 的普通铜间距也不受过孔专用规则影响。

这次修改没有修复检查记录中的孤立 GND 铜区，也未调整 USB 串联电阻。若改为其他板厂、铜厚或孔加工工艺，需要按对应订单能力重新核对。
