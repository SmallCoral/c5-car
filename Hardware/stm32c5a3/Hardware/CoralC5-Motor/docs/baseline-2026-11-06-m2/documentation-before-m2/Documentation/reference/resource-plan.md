## 主控分配原则

当前Motor引脚已按实际布局重新分配，见[GPIO分配表](motor-core-pins.md)。
左编码器使用TIM5，右编码器使用TIM2，左右PWM使用TIM4；这三个计数器不再分配给M2其他功能。
电流采样使用PH5和PC0，PA0/PA1已用于编码器，不能继续按旧表接ADC。
USART2、I²C1、USB和双线SWD保留。

新增光栅需要SCK、串行DATA、并行锁存和4组发射控制。
感为辅助板可采用8路数字输入，或CLK输出＋DAT无上下拉数字输入，另需供电和共地；当前尚未冻结接法及C5触点，不再按旧12路ADC复用方案分配引脚。
角度探头需要I²C，步进需要定时器STEP、DIR、使能、UART与回零/限位输入。
图传需要独立UART传时间戳和状态；microSD由图传处理器管理，避免占STM32控制带宽。
上述新引脚尚未冻结；需对照DS15137复用表、DMA/中断和实际网表统一分配。
没有核实复用功能的备用GPIO不在本表写成确定的SPI或定时器引脚。

## 探头接口建议

光栅接收条靠近光敏器件放4片HCS165，短距离传原始光电信号。
对外建议12针：5V、GND、3.3V_A、GND、SH_LD、CLK、DATA、GND、LED0、LED1、LED2、LED3。
该针序仅为M2建议，连接器料号与防反插方案在绘制时冻结。
跨摆杆铰轴的线束使用固定夹和柔性余量。

当前循迹由辅助板完成本体的选通与ADC采样，主板读取数字结果；辅助板供电、输出电平和连接器方向另行核实。旧自研探头的ADC复用器与LED控制电路不作为这套现成模块的已实现接口。
图传不能在主板与远端相机之间任意延长DVP；线长、时钟和连接器需要实测。
如果摄像头必须装高，优先把自研图传处理器靠近相机，仅用UART/电源连接Motor。
这属于自研分布式探头，主驱动与控制仍集成Motor。

## 电源必须重新预算

现有M1的4A保险丝、DC-005入口和5V/0.75A预算是两轮方案，不能原样视为支持所有新增负载。
新增步进相电流不等于电池电流，先测相电阻并按铜耗及驱动效率估算，再测代表性轨迹输入功率。
按两轮约4A瞬时限流上界叠加步进、图传和光学负载，入口可能超过原4A保护方案。
因此M2应比较XT30等入口、线径、保险丝I²t和铜箔热设计；不能只把保险丝调大。
原有背靠背MOS、TVS和USB隔离仍需整体复核。

Core的3.3V只保留参考和小负载。
单独辅助3.3V建议按至少1A的设计预算选电源，覆盖无线瞬时、逻辑和探头；这是设计预算，非测量值。
5V给红外发射及摄像头组件时，要按具体成像组件确认其是否自带1.2/2.8V稳压。
3S电池自带BMS，板上不新增不完整的锂电充电方案。
旧的一小时续航估算不包含新增步进和图传，不能继续作为M2续航结论。
