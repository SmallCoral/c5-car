# A 题机械与3D模型大纲

日期：2026-11-03。
本轮交付模型分解、参数和验证要求，不把参数草案当作已完成的STEP或可打印STL。
源CAD、加工文件和可视外形分开维护，工程入口见[Mechanical](../../Mechanical/README.md)。

## 机构总方案

双轮差速底盘加被动万向轮，电池贴近底板，摆杆位于车体纵向。
摆杆一端通过轴承铰接，另一端由固定在底盘上的42步进电机、曲柄和连杆抬升。
AS5600装在实际摆杆铰轴，径向充磁磁铁随轴转动。
摆杆及钢球重量由铰轴和连杆承受，不把全部悬臂负载压在电机轴承上。

首版底板暂定245×180mm，摆杆暂定280mm。
这是建模起点，250mm底板约束来自AC器材清单，不直接推定为整车包络限制。
摆杆外伸、轨道高度与光学支架的整车限制需要核实。
机械参数集中在[parameters.yaml](../../Mechanical/parameters.yaml)。

## 重点尺寸与自由度

1. 先实测MG513法兰、安装孔、轴径与轴长，再画支架；已有STEP只能作为参考。
2. 实测42电机的轴和安装孔，不能只按“42”复制任意NEMA17模型。
3. 首版铰轴离平板90mm，控制工作角暂定±3°，硬限位暂定±6°。
4. 280mm杆在−6°时自由端下降约29.3mm，90mm铰高给出约60.7mm最低高度；仍需加实物槽底和结构偏置核算。
5. 曲柄半径先保留10～25mm可调孔，连杆铰点距摆杆铰轴约250～270mm，最终以运动学行程校核。
6. 球槽不能夹球，端部加软挡；不通过给赛场钢球贴标、打孔或涂层来改善检测。
7. 光轴高度随球半径与槽截面变化，做可调孔，不固定为9mm后兼容所有球径。
8. 电机线与敏感光学、角度线分开走线；摆杆线束留弯曲半径和拉力释放。

## 建模基准

整车坐标：X向前、Y向左、Z向上。
轮轴中心线、底板上表面和摆杆端部铰轴分别建立基准。
装配保留两个轮轴转动、被动轮自由度、一个摆杆转动和执行连杆铰接。
使用参数和装配约束表达几何关系，不把每个零件固定死后截图当作运动检查。

## 文件交付要求

| 文件 | 要求 |
| --- | --- |
| 原生CAD | 可编辑、参数化、保留零件和装配层次 |
| STEP | 交换模型，毫米制，整车及关键分总成分别导出 |
| STL/3MF | 只导出打印零件，标明材料、方向、孔后加工和版本 |
| DXF | 板材加工用，核对比例、闭合轮廓和孔径 |
| 装配图 | 标明连接器1脚、拆装方向、运动范围及线束长度 |
| 物料表 | 打印件、标准件、轴承、磁铁、联轴件、电池固定件分别列出 |

先做电机座试装、4～8路光学槽段和单轴摆杆，再完成整车CAD。
不要等所有机械件打印后才首次验证光路和钢球高度。
元器件STEP完整绑定不代表底盘、摆杆和整车干涉已经验证。
