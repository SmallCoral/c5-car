# 2026-11-06 外接模块与灰度资料核对

源码基点：`4cf36a2ce5a0d5bb6b469a9a82320fcfbcc38c1f`。范围是模块资料清点、用户新 ZIP 与实物照片识别、灰度接口和支架文件查找。

使用 Python 3.12.14 的 `zipfile`、`hashlib`、`sqlite3`、`pypdf`，浏览原厂网页；以 Poppler 渲染钣金图纸，以 SolidCraft CLI 渲染 STEP，FreeCAD 1.1.4 检查实体。只读压缩包成员和 SQLite，未执行包内工具、固件或商家操作指令。

原厂 PDF 在网页工具中因文件大小限制返回 400，随后使用公开原始链接下载并在本地阅读；支架 ZIP 的网页打开出现 Cache miss，公开下载成功。最初 EPRJ 解码因 `base64` 前缀报错，剥离该格式前缀后以 gzip 解压成功，没有改写原工程。

辅助板源码与主控示例被分别阅读，没有把旧 M0 GPIO 或调试 UART 当作 C5 引脚。厂家有 MCU 成品灰度的 I²C、开漏和上拉说明，与用户这套无 MCU 本体加辅助板分别记录。
